# Clan Sound

Plays a sound of your choice whenever a clan chat message arrives.

## How to use

1. Turn on **Clan Sound** in the RuneLite plugin list.
2. Click the orange Clan Sound icon in the right-hand sidebar.
3. Press **Choose sound file (.wav)** and pick a WAV file. It plays straight away so you can check it.
4. Use **Test sound** to hear it again, and the **Volume** setting in the plugin's config to adjust it.

## Notes

- Only standard WAV files are supported. Convert MP3s to WAV first.
- The plugin keeps its own copy of your sound in RuneLite's plugin data folder, so your original file is never changed or needed again.
- It plays for clan chat and guest clan chat messages.
