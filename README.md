# Clan Sound

Plays a sound of your choice whenever a clan chat message arrives.

## How to use

1. Turn on **Clan Sound** in the RuneLite plugin list.
2. Click the black and purple sound icon in the right-hand sidebar.
3. Press **Choose sound file (.wav)** and pick a WAV file. It plays straight away so you can check it.
4. Use **Test sound** to hear it again.

## Settings

- **Volume:** how loud the sound is, from 0 to 100.
- **Ignore my own messages:** on by default. Turn it off if you also want the sound when you send a message yourself.
- **Cooldown (seconds):** the minimum time between sounds. Messages that arrive during the cooldown stay silent, so sounds do not overlap. Set it to about the length of your sound. 0 turns it off.

## Notes

- Only standard WAV files are supported. Convert MP3s to WAV first.
- The plugin keeps its own copy of your sound in RuneLite's plugin data folder, so your original file is never changed or needed again.
- It plays for clan chat and guest clan chat messages.
- If RuneLite is minimised or running slowly in the background, messages can be processed late. Keep it visible for the most reliable sounds.
